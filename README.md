# Data is Not Neutral: A Political Economy of Business Intelligence
**Author:** Hassan Gasem
**Abstract:** This paper argues that Business Intelligence systems encode power relations and structural inequalities. It introduces the BI Power-Alignment Framework (BPAF) for analyzing extraction, representation, and execution of organizational data practices.

## Key Points
1. BI systems are political, not neutral.
2. BPAF framework analyzes Extraction, Representation, Execution layers.
3. Implications for emancipatory BI, data ethics, and governance.
